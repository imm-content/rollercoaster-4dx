# 🎢 가상 롤러코스터 4DX 시네마

GLB 파일 없이 **Three.js와 HTML5만으로 제작한 1인칭 롤러코스터 체험**입니다.

## 실행

GitHub 저장소 이름: **`rollercoaster-4dx`**  
권장 계정: **`imm-content`**

1. 저장소를 Public으로 생성합니다.
2. `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 설정하고 저장합니다.
5. 배포 후 `https://imm-content.github.io/rollercoaster-4dx/`로 접속합니다. (계정명이 정확히 `imm-content`일 때)

> Three.js는 CDN에서 불러오므로 최초 접속 및 실행 시 인터넷 연결이 필요합니다.

## 체험 구간

| 구간 | 내용 |
| --- | --- |
| 1막 | 롤러코스터 탑승 및 출발 |
| 2막 | 높은 철로를 따라 상승 |
| 3막 | 정상에서 급강하 |
| 4막 | 360도 수직 루프 |
| 5막 | 터널과 급회전 |
| 6막 | 감속 및 도착 |

## 조작

- **탑승 시작**: 자동 주행 시작
- **일시정지 / 계속**: 주행 중지 또는 재개
- **처음부터**: 출발 상태로 초기화
- **체험 강도**: 완만 / 보통 / 스릴 (주행 속도 및 흔들림 조정)
- **화면 흔들림**: 시각적 진동 켜기 / 끄기
- **소리**: 브라우저에서 생성한 간단한 기계음 켜기 / 끄기

## 구현 방식

- HTML / CSS / JavaScript
- Three.js 0.160.1 (CDN, ES Module)
- Catmull-Rom 곡선을 활용한 철로 및 카메라 경로
- TubeGeometry로 철로, 기본 도형으로 지지대·나무·차량 일부·터널 구성
- Web Audio API를 활용한 간단한 합성 주행음
- GLB, 이미지, 음향 파일 등 외부 에셋 없이 실행

## 안내 및 주의사항

이 콘텐츠는 실제 4DX 장비를 제어하지 않는 **웹 기반 4DX 스타일 시뮬레이션**입니다. 물리적 좌석 움직임, 바람, 물 분사 기능은 없습니다.

화면 움직임으로 어지럼증이나 멀미가 발생할 수 있습니다. 불편하면 즉시 일시정지하고, **완만 모드** 및 **화면 흔들림 끄기**를 사용하세요.
